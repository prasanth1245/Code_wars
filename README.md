# ⚡ MARVEL CODE WARS — CYBORGS'26

A dynamic, high-performance web application built for **Marvel Code Wars**, an inter-collegiate technical contest hosted by the **Department of Computer Science and Engineering**.

---

## 🌐 About The Website

The **Marvel Code Wars** web application serves as the official digital portal for the competition under **CYBORGS'26**. Designed with an immersive Marvel/Thor cosmic aesthetic, the portal provides participants with an engaging experience from entry to registration.

### Key Highlights
- **Cosmic & Lightning Aesthetic:** Built with custom ambient dark mode styling, radial gradients, glowing particle effects, and Thor-themed lightning backdrops.
- **Intro Experience:** Integrated splash video sequence with background scrolling locks, manual skip options, and automatic timeout fallbacks.
- **Interactive Event Flow:** Clear breakdown of contest rounds, mission objectives, and rules to guide participants through the challenge structure.
- **Organizing Team Showcase:** Includes a full group feature and balanced individual member profile cards showcasing the student organizing committee.
- **Direct Portal Integration:** All Call-To-Action (CTA) buttons seamlessly route users directly to the main registration portal.
- **Responsive Engineering:** Fully responsive layout built with CSS Grid and Flexbox, optimized for all screen sizes from mobile devices to desktop monitors.

---

## 🛠️ Tech Stack

- **Frontend Framework:** React.js, Vite
- **Animations:** Framer Motion
- **Icons:** React Icons (`fa6`)
- **Styling:** CSS3 (Flexbox & CSS Grid)
